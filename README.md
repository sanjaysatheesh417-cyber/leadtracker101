# About the project
This is a simple Lead Tracker Chrome extension made using javascript, HTML and CSS.
I made this project as a part of learning javascript.

# whats different from a regular lead tracker?
I have integrated a confetti sound effect that is played everytime you press a buttom to save a tab, input or delete all tabs.

# Getting Started
1.Download the zip file from github and extract it in a folder.

2.Install the dependencies and run the project
```
npm install
npm start
```
3.go to the chrome extensions in chrome and switch on the developers mode

4.click load unpacked and select the folder.

5.Now, you can use the chrome extension from chrome extensions to save any profile or page!!!!
